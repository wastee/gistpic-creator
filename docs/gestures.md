# 界面手势

整个窗口就是一张画板：没有顶栏、没有右侧抽屉、没有固定状态栏，也没有双击弹出的放大窗口。所有操作都在画布、底部胶囊和右键卡片上完成。

## 鼠标

| 做什么 | 怎么做 |
| --- | --- |
| 选中一张 | 左键单击图片 |
| 多选 / 取消多选 | `Ctrl/Cmd` + 左键单击，或在画布空白处按住右键拉框 |
| 全选 | `Ctrl/Cmd + A`（作品为空时不做任何事） |
| 移动窗口 | 在画布空白处按住左键拖动；还没导入图片时，空状态卡片以外的空白也能拖 |
| 平移画布 | 按住鼠标中键拖动，画布内容跟着指针走；只在作品超出窗口时有效 |
| 横向看宽成品 | 按住 `Shift` 滚轮左右滚 |
| 调整顺序 | 按住图片中间拖到另一张图上，指针一盖住目标图片就换序 |
| 原地调裁剪 | 鼠标停在图片上，按住任意一条边线拖动 |
| 同步裁剪 | 横排拖上下边、竖排拖左右边会整组一起改；其它情况先多选，再拖任意一张的裁剪线 |
| 调图片间距 | 按住作品左边竖药丸上半部分的方块按钮上下拖（两种模式都一样） |
| 精细调整 | 按住 `Shift` 拖裁剪线或缝隙按钮（竖药丸上的方块按钮），数值每次只走 1 像素 |
| 换缝隙颜色 | 单击竖药丸下面的色点，间距为 0 时也能点 |
| 删除图片 | 按住图片拖到底部胶囊的垃圾桶上，它变红时松手；或按 `Delete` |
| 缩放画布 | `Ctrl/Cmd` + 滚轮，或 `Ctrl/Cmd + + / - / 0` |
| 看成品别处 | 成品放大到超出窗口时，拖画布左下角预览框里的方框 |
| 回到默认缩放 | 点画布右下角比例胶囊里的「适合画布」 |
| 回到原始像素大小 | 点画布右下角比例胶囊里的「1:1」 |
| 换排版方式 | 点底部胶囊里的横排、竖排或循环排版（点一下换一种拼法，行业叫 Shuffle Layout） |
| 图片右键卡片 | 在图片上点右键 |
| 全局右键卡片 | 在画布空白处或胶囊上点右键 |

## 拖动图片

按住图片中间拖动时，指针下方跟着一张半透明小图（最长边 88 像素），被拖的图片原位置立刻被后面的图片补上，松手之前排版就按落点让位，被拖的那张以半透明虚线占位显示在新位置，一眼能看出松手后会排成什么样。指针落到另一张图片上的任意位置就按拖动方向换序：原来在前面的往下拖，就插到那张后面；原来在后面的往上拖，就插到那张前面，不用拖到边缘。

指针靠近窗口上下边缘时画布会自动持续滚动，指针不动也会滚，方便把图拖到远处。

拖动时底部胶囊缩成一个安静的垃圾桶，鼠标压上去才张开、变红、提示松手删除。

## 裁剪线

鼠标一进入图片就立刻浮出这张图被裁掉的区域，不等待、不淡入；被裁掉的区域用一条很淡的线表示，只有正在拖的那条边会亮起来变成一段短圆角条，约 120 毫秒显现，松手后 500 毫秒淡回去。

拖哪条边，画面就朝哪条边的方向伸缩，对面那条边留在原来的屏幕位置：拖上边时上方空间跟着往上走、下面的图不动；拖下边、左边、右边同理。字幕模式、排版模式、四条边和所有排版方式（横排、竖排、循环排版）都是这个规则。上方留白让完之后，剩下的位移由画布滚动补上。

上下两条线靠近单行字幕、双行字幕、整张画面时自动吸附。排版模式下图片无论收得多窄，四条边都还留得住可以抓的区域；字幕模式只有上下两条边，2% 的下限已经按屏幕显示比例算过，仍然点得中。

排版模式裁剪时每张图至少要留下宽高各 15%（面积不低于 2.25%）；字幕模式只调上下两条边，高度至少要留下 2%，不套面积下限（作品按窗口显示比例缩小时，2% 的高度还抓得住裁剪线，也低于自动识别的最细字幕带 3%，手动能收到比自动识别更小）。两种模式拖到下限后继续往同一个方向拖都不会再有变化。

字幕模式下，左右两条边不能拖，只有上下两条裁剪线能动。

横排时拖动上下裁剪线，所有图片一起改高度（画面被裁掉一部分，不拉伸）；竖排时拖动左右裁剪线，所有图片一起改宽度。同一排或同一列的图算一组，拖组里任意一张的边，组内其它图按同样的量一起改。

两张图紧贴（间距 0）时，接缝两侧各 3 像素不响应鼠标，避免调整一张图时误碰相邻那张；间距大于 0 时不生效，热区照旧贴住裁剪线铺开。

### 按住 `Shift` 精细调整

按住 `Shift` 拖裁剪线时，数值变化速度是平时的 1/8，并按这张图在画布上的显示比例自动换算：图按 40% 显示时约 3 个屏幕像素动 1 个原图像素，100% 时约 8 个，400% 时约 32 个。数值按原图整像素走，不会停在半个像素上；拖动时正在拖的那张图裁剪后的「宽 × 高」显示在正在拖的那条边旁边，单位是原图像素。

按住 `Shift` 期间，上下两条边的磁吸（单行、双行、整张画面）关闭，裁剪线不会吸到这些档位；松开 `Shift` 后磁吸恢复。

拖动中途按下或松开 `Shift` 会立即切换速度，裁剪线停在原处，数值不跳变。

## 缝隙控件

两种模式调图片间距用同一个控件：挂在作品左边的竖药丸，纵向固定在可见画布的正中间，作品上下滚动它不动。上面是缝图标、下面是当前缝隙颜色的圆点。

改间距只能按上半部分那个方块按钮，按药丸的其他地方不动间距；鼠标进入药丸后约 120 毫秒变清晰，离开后 500 毫秒淡回半透明。

按住按钮上下拖动改间距（0 到 100 像素，往上变窄往下变宽），拖动时药丸正下方固定显示当前像素数，带一条细刻度表示间隙程度，不跟鼠标跑、不画边框，松手后淡出。

按住 `Shift` 拖动按钮时走精细调整：速度是平时的 1/8，每次只改 1 个成品像素；药丸正下方的数值气泡照常显示当前像素数。

点圆点在纯白、炭黑、暖灰三种缝隙颜色之间循环，间距为 0 时也能先选颜色。

## 缩放和预览框

画布右下角的比例胶囊上，左边那个百分数是显示像素和成品输出像素的比值（成品 4000 像素宽、屏幕上显示 1000 像素就是 25%），右边两项「适合画布」和「1:1」一直可见：前者把整幅成品画布适配到可用区域、整张作品居中，最大 100%，不放大；后者回到成品原始尺寸，一个输出像素对一个画布逻辑像素，超出窗口时滚动查看。可用区域是窗口去掉左右各 48 像素、顶部 24 像素、底部 96 像素之后剩下的部分。当前生效的那一项是蓝底白字；用滚轮或加减键缩放到别的比例时，两项都不高亮，只有左边的百分数跟着变。

手动缩放范围是 0.1% 到 400%，「适合画布」是单独一档，不属于这个范围。按「适合画布」时用整幅成品画布重算，不保留上一次手动缩放的值；按过「1:1」或手动缩放过以后，点「适合画布」重新按窗口算。空白画布（刚启动、第一次导入或粘贴、清空或删掉最后一张图之后）默认就是「适合画布」，有图以后手动缩放的比例照常保持。

作品在放大后超出可视区时，画布左下角出现一个预览框：里面是整张成品的缩略图，缩略图按成品比例缩放后放在框的正中间，上面那个方框表示当前看到的范围，拖方框就能平移到别处，缩放和成品数据都不变；方框拖出边界自动夹住。默认不透明度 30%，鼠标压上去才变清晰，离开后 500 毫秒淡回。作品一屏放得下时不显示。

## 成品的显示尺寸

「适合画布」只看整幅成品画布：字幕模式是拼好的那张长图，排版模式是横排、竖排、循环排版排完之后的画布。程序拿成品画布的宽高去比可用区域，比例取「可用宽 ÷ 成品宽」和「可用高 ÷ 成品高」里小的那个，再限制在 0.1% 到 100% 之间。成品比可用区域大就按这个比例缩小，成品比可用区域小就停在 100%，不放大。

字幕模式、横排、竖排、循环排版用的是同一套算法，所以不同形状的成品会得到不同的百分比，这是正常的。比如 1381×804（宽×高）的窗口里，可用区域是 1285×684；1920×1080 的单张成品按高度算约 63.3%，显示约 1216×684。同一批图拼成更长的成品以后，百分比会跟着变小。

成品缩得很小时比例会低于 5%，最低到 0.1%。比如 3840×21600 的竖排成品放进 1381×804 的窗口，只剩约 3.2%，要放大或滚动看细节。

成品最窄的那条边在画面里居中：竖长图（比如 10×10000，宽 10、高 10000）在左右方向居中，宽矮图在上下方向居中；字幕模式、横排、竖排、固定比例都一样。

只有成品高到会钻到底部胶囊底下时才往上让、靠纵向滚动看全，其余时候都在画面正中。

## 右键卡片

**图片上点右键**：保留单行 / 双行 / 整张画面、同步裁剪、恢复自动结果、上移 / 下移 / 删除。

**画布空白处或胶囊上点右键**：打开图片、粘贴、清空、中英文切换、关闭到托盘、复制或导出后清空图片、退出。

版本号不放进右键卡片。空白画布的空状态卡片里，版本号跟在支持格式下方，和上面隔 12px，用 10px 字号和弱提示色（版本号以 `Cargo.toml` 的 `version` 为准，写这份文档时是 `v1.2.0`）；鼠标停在托盘图标上也能看到 `省流图创造机 v1.2.0`，其中 Windows / macOS 直接显示系统提示，Linux 是否显示由桌面托盘宿主决定。右键卡片最下面一栏就是「退出」。

右键卡片画在主窗口内，紧贴鼠标弹出。菜单从鼠标处向右下展开；鼠标靠近窗口右边缘或下边缘、菜单放不下时，就翻到鼠标的左边或上方，仍然贴着鼠标，保证整张卡片都在主窗口内。翻转按菜单实际测量出的尺寸计算，所以卡片边缘始终贴着鼠标；语言二级菜单和主卡片作为整体一起翻转，一起留在窗口内。

没找到字幕的图片默认输出整张画面，不再弹窗询问；识别失败的图片也会保留整张画面。右键卡片里的「整张画面」开关反映当前输出范围，手动框选只改这张图的输出范围，不会重新跑字幕识别。

### 复制或导出后清空图片

画布右键卡片里有开关「复制或导出后清空图片」，默认关着，选择会记住。

- 开着的时候，每次复制或导出成功后，主窗口会盖上一层深色遮罩把画面压暗，中间只有一个大号秒数，持续一呼一吸地变亮变暗，倒数 3 秒。遮罩上没有面板、边框、提示文字这些多余元素。
- 倒数期间点窗口任意处就取消，图片不会被清掉。
- 按 `Esc` 不会取消倒数——`Esc` 是拿来关窗口的；要取消只能点遮罩。
- 没人取消的话，倒数结束自动清空作品；这次清空和普通清空一样记进撤销历史，按 `Ctrl/Cmd + Z` 就能撤销回来。
- 复制或导出失败、或没有图片时不会启动倒数。

## 系统托盘与关闭按钮

程序运行时会在系统托盘显示一个图标。图标用的是 `assets/icon.png`：深色圆角底，左边三条字幕横条，中间一道闪电，右边一张图片。macOS 菜单栏要单色模板图，程序会把这张图按亮度转成白色剪影。

- **Windows / macOS**：左键点图标直接把窗口叫到前面；右键弹出菜单。
- **Linux**：图标由桌面显示，左键行为由桌面决定（GNOME 上通常是弹出菜单）；菜单里始终可以点「打开主窗口」。
- 菜单内容只有两项：「打开主窗口」和「退出」。
- 退出：按 `Ctrl/Cmd + Q`，或点窗口自带的关闭按钮（关掉「隐藏到托盘」时），或托盘菜单里的「退出」。
- 关闭按钮、`Ctrl/Cmd + Q`、托盘菜单里的「退出」、`Esc` 隐藏都会保存当前选项和窗口大小；下次启动按保存的值恢复。

### 关闭按钮

右上角关闭按钮平时很淡；指针进入或靠近窗口右上角区域时，它才淡入变亮。

在画布空白处或底部胶囊上点右键，卡片里有开关「关闭窗口时隐藏到托盘」：

- 开着（默认）：点窗口关闭按钮会隐藏窗口，程序继续在托盘运行。
- 关掉：点窗口关闭按钮直接退出程序。
- 这个开关会记住，下次启动保持上次的选择。

按 `Esc`：先关掉右键卡片这类浮层；复制或导出后的清空倒数不算浮层，按 `Esc` 不会取消它。没有浮层可关时，开着「关闭窗口时隐藏到托盘」就隐藏窗口到托盘；关掉这个开关则 `Esc` 不做任何关闭动作。

### 窗口隐藏后怎么找回来

Windows / macOS / Linux：点托盘图标或菜单里的「打开主窗口」会重新显示窗口。

Linux Wayland 下窗口会重新显示，但桌面可能拒绝程序主动把窗口提到最前面；需要时用桌面自带的任务栏或窗口列表。

### 配置文件

配置文件只记界面选项和窗口大小位置，不记图片列表，也不记单张图片的裁剪范围。

记住的选项包括语言、模式、裁剪开关、保留第二行、字幕边距、缝隙开关 / 宽度 / 颜色、排版方式、关闭到托盘、复制按钮的小图模式、复制或导出后清空图片。

显示比例不进配置文件，启动时不恢复上次的缩放：空白画布一律用「适合画布」，第一次导入或粘贴图片时按整幅成品重新适配。旧配置文件里存过的显示比例会被忽略，其它选项照常读取。

首次启动或没有有效窗口记录时，按 1240×720（宽×高）居中打开，不最大化。Windows / macOS / X11 下窗口位置也恢复，Wayland 下位置由桌面决定。

文件在用户配置目录下的 `gistpic-creator/state.json`。文件内容有问题时程序会用默认值启动并保留原文件，不会覆盖。

## 语言

桌面界面支持简体中文和英文，默认简体中文。在画布空白处或底部胶囊上点右键，卡片里可以随时切换语言；窗口标题、托盘菜单、胶囊提示和导出文件名会一起切换。
